# 场景六：供应链穿透与断供风险图谱

> 状态：**概要** —— 技术栈与 [场景一](./01-金融风险传导图谱.md) 高度重叠，建议作为其一期扩展，不单独起项目。

---

## 0. 一句话

构建「整机-部件-供应商-物料」多层供应网络，用**割点分析**找单点依赖、**最短路径**做 N 级穿透合规筛查（制裁名单 / 冲突矿产），用工作流实现「名单更新 → 穿透 → 命中 → 人工确认 → 告警」的自动化监测。

---

## 1. 数据源与量级

| 数据源 | 类型 | 量级 | 入库方式 |
|---|---|---|---|
| 供应商档案 | 结构化 | 十万级 | ETL 直入 |
| BOM / 物料主数据 | 结构化 | 百万级行 | ETL 直入 |
| 采购合同 | 半结构化 | 十万级 | LLM 抽取 + 规则 |
| 招投标公告 | 半结构化 | 千万级 | LLM 抽取 + 规则 |
| 海关进出口数据 | 结构化 | 百万级 | ETL 直入 |
| 制裁 / 实体清单 | 结构化 | 万级 | 定期同步 |
| 工商股权 | 结构化 | 亿级 | 采购 |
| 新闻 / 舆情 | 非结构化 | 日增数万 | LLM 抽取 |

图规模：供应商 + 物料 + 工厂节点百万级，供货/替代/控股关系边**百万至千万级** → 单机 GDS 可承受。

## 2. 本体骨架（草案）

| 本体 | 关键属性 |
|---|---|
| 供应商 | 名称、编码、类型（一级/N级）、地域、资质认证、评级 |
| 物料 / 部件 | 物料编码、名称、规格、品类、是否关键件、独家性 |
| 品类 | 品类代码、层级 |
| 工厂 / 产地 | 名称、地域、产能 |
| 客户 / 整机 | 产品型号、产线 |
| 认证资质 | 认证类型、有效期、认证机构 |
| 合同 | 合同号、金额、起止日、独家条款 |

**关系**：`供货` `替代` `控股/独资` `产地位于` `同址` `独家供应` `属于品类` `通过认证` `采购自` `组装为`

## 3. 图计算算法映射

| 算法 | 业务问题 |
|---|---|
| **割点 / 桥（Articulation Point）** ⭐ | 断掉哪个供应商会导致供应链断裂？→ 单点依赖识别（最有杀伤力的一个） |
| **加权最短路径** | N 级供应商穿透 —— 我的三级供应商里有没有制裁名单企业？ |
| **中心度（Betweenness）** | 哪些物料是瓶颈？ |
| **社区发现** | 供应商地域集群（同地域 = 同风险敞口，如自然灾害、政策变化） |
| **PageRank** | 关键供应商影响力排序 |
| **连通分量** | 单一工厂停产后影响的产品范围 |

## 4. 工作流闭环

```
[定时节点] 每日同步制裁名单 / 实体清单
    │
    ▼
[代码节点] 名单与图谱实体对齐（含别名与股权穿透后的最终受益人）
    │
    ▼
[图计算节点] N 跳穿透（默认 N=3）+ 割点分析
    │
    ▼
[条件分支] 命中名单企业 / 存在单点依赖 ?
    ├─ 是 → [人工节点] 采购 & 合规确认（form 模式：定性 / 是否切换 / 备选方案）
    │        → [通知节点] 告警
    └─ 否 → [结束]
```

## 5. 契合度与风险

| 维度 | 评价 |
|---|---|
| 本体约束 | ★★★★☆ |
| LLM 抽取 | ★★★★☆ 合同与公告抽取有价值，BOM 走 ETL |
| 图谱 | ★★★★★ 穿透与割点是刚需 |
| 工作流 | ★★★★★ |
| 图计算 | ★★★★☆ |
| 图计算框架 | 否（百万~千万边，GDS 足够） |

**风险**

1. 供应商数据是企业核心资产，甲方通常只提供部分数据，覆盖率是落地最大障碍。
2. N 级穿透依赖工商股权数据，需采购；纯靠公开数据穿透深度有限（一般到 2 级）。
3. 制裁名单合规属于强监管领域，判定结论必须由人工确认，系统只做线索提示。
