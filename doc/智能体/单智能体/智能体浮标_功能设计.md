# 智能体浮标（全局助手）功能设计

> v1.0 · 2026-09-25 · 全局悬浮智能体入口，系统任意页面可唤起对话

## 1. 定位与目标

- **全局可达**：浮标固定在右下角，系统所有页面（含 fullscreen 页面）可见，点击弹出对话抽屉。
- **一站式问答**：一个问题入口覆盖「功能怎么用」「查数据」「查图谱」「知识库检索」等所有诉求，无需用户判断该去哪个页面。
- **轻量壳、重能力**：浮标只是对话壳，能力全部复用现有多智能体 universal 场景链路（0.6B 意图路由 + 取证团队 + SSE 流式），零新增后端代码。

## 2. 交互设计

### 2.1 浮标（FAB）

- 右下角固定（right: 24px / bottom: 24px），56px 圆形，机器人图标 + 主题强调色渐变 + 呼吸光圈动画。
- 运行中在浮标上显示脉冲小绿点，提示后台仍在作答（抽屉收起不打断任务）。
- 点击浮标开/关对话抽屉，ESC 可关闭。

### 2.2 对话抽屉

- 从浮标上方弹出，宽 400px、高 min(620px, 72vh)，圆角卡片 + 阴影。
- 头部：标题「智能助手」+ 一句话能力说明 + 「新会话」按钮 + 关闭按钮。
- 消息区：用户消息右对齐、助手消息左对齐气泡；助手内容 markdown 渲染（marked，与协作页同口径 v-html）。
- 过程状态：助手气泡上方一行轻量状态文本（如「正在数据查询…」「交叉评审 ✓」），节点级细节不展开——浮标追求轻，重过程回协作页看。
- 澄清卡：后端判任务信息不足时，内联展示澄清问题 + 候选 chips + 自行补充输入，确认后以「原任务（补充说明：…）」clarified 重发（语义与协作页一致，防澄清循环）。
- 输入区：textarea 自适应高度（≤4 行），Enter 发送 / Shift+Enter 换行；运行中变「停止」按钮（AbortController 断流）。

## 3. 能力路由（复用，无新增）

用户在浮标问任何问题，走 `POST /api/agent/multi/scenarios/universal/run`（SSE）：

| 用户意图 | 后端行为 | 浮标呈现 |
| --- | --- | --- |
| 功能/用法咨询（chat 高置信） | 直答，不启团队 | 流式文本回答 |
| 平台知识/文档问题 | 知识检索取证据后作答 | 流式文本回答 |
| 查数据（「有多少…」「本月告警」） | NL2Filter 抽取 → DataAgent NL2SQL | 状态行 + 统计/明细文本 |
| 实体关联/关系链 | GraphAgent 图谱检索 | 状态行 + 事实文本 |
| 任务过简 | clarify 事件 | 澄清卡（chips + 自填） |

## 3.5 深度模式（DeepAgents 架构）

浮标输入区左侧「深度」开关（运行中禁用切换），开启后请求携带 `deep=true`：

- **执行路径**：`POST /scenarios/universal/run` + `deep=true` + 总闸 `DEEP_AGENT_ENABLED`（.env 已开）双确认 → `services/multi_agent/deep_agent.py` 的 `DeepAgentRunner`——DeepAgents（LangChain 官方 agent harness，deepagents 0.7.15）在 LangGraph 之上提供 **LLM 自主规划（write_todos 待办清单）+ 虚拟文件系统上下文卸载 + 可选子智能体（`DEEP_AGENT_SUBAGENTS=true` 时主代理经 task 工具派发 kb_researcher / graph_researcher / data_analyst 三个隔离上下文子研究员）**。
- **工具链**（与取证节点同源取数，口径一致）：`deep_kb_search` 跨库语义检索 / `deep_graph_search` 图谱关系链 / `deep_data_query` 台账 NL2SQL。模型 = 配置页启用计划（当前 glm-5.3-flash；GLM 系列在 DeepAgents 评测中表现最佳）。
- **同契约零改动**：DeepAgentRunner 与 MultiAgentEngine 同契约（q / team_info / run），SSE 事件、会话留痕、浮标渲染全部复用；团队帧 `team` 含「深度智能体」时浮标状态行显示「深度研究员 · 自主规划取证中」。
- **回落保护**：总闸关闭或 deepagents 未安装时后端静默回落标准团队路径；浮标检测到「请求深度但团队帧非深度」时显示橙色提示「深度模式不可用（后端总闸未开），已回落标准协作路径」。
- **取数范围**：浮标深度模式不传 kb_id / data_sources——跨全部知识库检索、自动发现全部数据源类别，符合「系统级问答」定位。
- **适用场景**：多阶段复杂任务（「对比 A 和 B 的制度差异并给出数据佐证」）；简单问答建议关深度（更快）。整轮超时 `DEEP_AGENT_TIMEOUT`（默认 300s），超时基于已有产出收尾。

- 多轮续聊：`session` 事件回传 session_id 后续问句自动携带，追问延续上下文；「新会话」清空锚点。
- 会话留痕：与协作页共用 chat_messages 落库，协作历史页可见浮标发起的会话。

## 4. 前端实现要点

- `components/agent/AssistantWidget.vue`：FAB + 抽屉一体组件；消息流状态机消费 SSE 事件（token/team/node_start/node_done/clarify/session/done/error），是 MultiAgentPage handleEvent 的轻量子集。
- 挂载点：`App.vue` 中 `router-view` 同级（`main-area` 之后），不随路由销毁；显示条件 `isLoggedIn() && hasPerm('agent:view')`（与多智能体页同权限）。
- SSE 复用 `api/multiAgent.js` 的 `streamTaskRun`（interceptor 自动注入 Bearer）。
- 节点名中文映射内置于组件（router/planner/nl2filter/retriever/data_agent/graph_agent/tool_agent/critic/synthesizer/chat_direct）。

## 5. 边界与后续

- 深度模式/手动组队/数据源多选等重操作不进浮标，引导去多智能体协作页。
- 后续可扩展：浮标拖拽记忆位置、上下文感知（携带当前页面路径作为问句上下文）、历史会话切换。
