# 模型微调方法体系（三个正交维度 × 方法全景）

> 回答核心问题：**SFT、FFT、RLHF、DPO、LoRA、QLoRA 不是同一维度的并列项**——
> 它们分属 3 个正交维度：**训练范式**（用什么数据教什么）、**参数范围**（动多少权重）、
> **数值精度**（是否量化）。日常说的"方法名"大多是这三个维度的组合词。
> 本项目映射：**LoRA + SFT**（LLaMA-Factory 一份 yaml 两个关键字：
> `finetuning_type: lora` 定维度②，`stage: sft` 定维度①）。

---

## 0. 一张表看清三个维度（正交、可自由组合）

| 维度① 训练范式（教什么） | 维度② 参数范围（动多少权重） | 维度③ 数值精度（量化与否） |
|---|---|---|
| CPT 继续预训练（领域语料） | FFT 全参微调（~100% 权重） | bf16/fp16 混合精度（默认） |
| SFT 监督微调（指令→回答对） | 部分层微调（冻结底层只训顶层） | 8bit LLM.int8 |
| RLHF 奖励模型 + PPO | PEFT 参数高效（<1% 权重） | 4bit NF4（QLoRA 用） |
| DPO 直接偏好优化（偏好对） | ↳ 低秩旁路：LoRA / QLoRA / DoRA | |
| GRPO 组相对策略优化（免价值模型） | ↳ 加性前缀/模块：Adapter / Prefix / P-Tuning v2 | |
| 蒸馏 大模型输出当 SFT 数据 | ↳ 缩放类：IA³ / BitFit | |

任一"方法名" ≈ 跨维度组合，例：

| 组合 | 维度①×②×③ | 是谁在用 |
|---|---|---|
| FFT + SFT + bf16 | 全参 + 监督微调 | 原厂炼 Instruct 版 |
| **LoRA + SFT + bf16** | 低秩旁路 + 监督微调 | **本项目意图路由（主流小模型改行为）** |
| QLoRA + SFT + NF4 | 4bit 主干 + LoRA + 监督微调 | 12G 小卡训 7B |
| FFT + SFT → FFT + RLHF | 三阶段对齐 | ChatGPT 式完整后训练 |

## 1. 维度①：训练范式（监督信号是什么）

**CPT（Continual Pre-Training，继续预训练）—— 领域基座团队的活，应用层很少亲手做，面试知道概念即可**
- 数据：领域海量无标注语料；目标：学"下一个词"（自回归 cross-entropy）；
- 用途：给基座**注入领域知识**（法律/医疗语料续训）；窄任务不需要，成本高。

**SFT（Supervised Fine-Tuning，监督微调）—— 一切后训练的地基**
- 数据：`instruction / input / output` 三元组（指令→标准回答对）；
- 目标：学"按指令办事"——行为对齐 + 输出格式稳定；loss 只算 output 部分；
- 与预训练的区别：预训练学**语言能力**（海量语料），SFT 学**指令行为**（小而精的任务数据）；
- 本项目的 4 分类 JSON 输出就是标准 SFT 场景。

**RLHF（Reinforcement Learning from Human Feedback，基于人类反馈的强化学习）**
- 三阶段：SFT → 人类标注偏好对训**奖励模型 RM**（Reward Model）→ **PPO**
  （Proximal Policy Optimization，近端策略优化）强化学习优化策略
  （用 KL 惩罚约束不偏离 SFT 初值太远）；
- 解决 SFT 管不了的问题："哪种回答**更好**"没有唯一标准答案，只能靠偏好相对比较；
- 缺点：流程重（要训 RM）、PPO 训练不稳、超参敏感、实现成本高。

**DPO（Direct Preference Optimization，直接偏好优化）—— RLHF 的简化替代**
- 核心洞察：RLHF 的目标可以数学变形，**跳过奖励模型和 RL**，直接用偏好对
  `(chosen, rejected)` 做一个类似分类的损失（隐式奖励 = 策略与参考模型的对数比）；
- 优点：等价优化目标、实现简单（一份偏好数据 + SFT 式训练即可）、稳定；
- 变体：**ORPO**（Odds Ratio Preference Optimization，比值偏好优化——并入 SFT 单阶段）、
  **KTO**（Kahneman-Tversky Optimization，卡尼曼-特沃斯基优化——只需单边好/坏标注）、
  **SimPO**（Simple Preference Optimization，简化偏好优化）、
  **IPO**（Identity Preference Optimization，恒等偏好优化）——知道名字和一句话区别即可；
- 位置：RLHF/DPO 都在 **SFT 之后**（先教会说话，再教偏好）。

**GRPO（Group Relative Policy Optimization，组相对策略优化）—— DeepSeek 系的 RL 简化**
- 出身：DeepSeekMath 提出，DeepSeek-R1 的推理能力训练就用它；
- 核心改动：同一 prompt **采样一组回答**，用组内奖励的相对比较（减组均值）当优势——
  **免 critic/价值模型**（PPO 要额外训一个与策略同大的价值网络估基线），
  显存与工程复杂度大幅下降；
- 与 DPO 的区别：DPO 把 RL 蜕化为**离线监督损失**（不再采样、不在线更新）；
  GRPO 仍是**在线 RL**（要采样、要 KL 约束），只是把基线从价值模型换成组内均值；
- 奖励来源与 RLHF 相同：偏好模型或规则奖励都行（R1 用规则奖励：答案对 + 格式对）。

**蒸馏（Distillation）**：严格说是 SFT 的**数据来源**——用强模型（大模型）生成回答
当 SFT 标签训小模型（如 DeepSeek-R1 蒸馏版）；**RFT**（Rejection Sampling Fine-Tuning，
拒绝采样微调）/ **STaR**（Self-Taught Reasoner，自举推理）：模型自己做对才保留为
训练数据，用于推理能力增强。

**选型直觉**：有标准答案 → SFT；只有"哪个更好"的相对偏好 → DPO/RLHF/GRPO；
要注入大量领域知识 → CPT。本项目 4 分类有唯一标准 JSON 答案 → SFT 足够，
暂不需要 DPO/RLHF（未来若要调"回答语气/拒绝边界"这类无标准答案的偏好才用得上）。

## 2. 维度②：参数更新范围（动多少权重）

**FFT（Full Fine-Tuning，全参微调）**
- 100% 参数参与更新；同数据下效果上限最高，但：显存最大（要存全部参数+梯度+优化器状态，
  约为参数量 × 16 字节）、易**灾难性遗忘**、每个任务存一份完整权重；
- 0.6B 也训得起 FFT，但本项目不用：小数据（1~2k 条）全参过拟合风险更高，
  且 LoRA 才是业界改窄行为的标准做法（面试口径一致性）。

**部分参数微调**（Partial Fine-Tuning）：冻结 Embedding/底层，只训顶层若干层；
**BitFit**（Bias-only Fine-Tuning，仅偏置微调）：只训所有 bias（~0.1% 参数）。
简单但容量受限，现在多被 PEFT 取代。

**PEFT（Parameter-Efficient Fine-Tuning，参数高效微调）—— 可训练参数 <1%**
- **低秩旁路类（当前主流）**：
  - **LoRA**（Low-Rank Adaptation，低秩适配）：冻结 W，旁路 `ΔW = B·A`（A 高斯初始化，
    B 零初始化），前向 `h = Wx + (α/r)·BAx`；理论依据：微调的更新量本征低秩；
  - **QLoRA**（Quantized LoRA，量化低秩适配）：LoRA + 把冻结主干量化为 4bit NF4
    （+Double Quantization 双量化 + Paged Optimizer 分页优化器）；
  - **DoRA**（Weight-Decomposed LoRA，权重分解低秩适配）：把权重分解为幅度×方向
    分别低秩更新，小秩下更接近 FFT；
  - **LoRA+**（LoRA with Different Learning Rates，A/B 差异化学习率）、
    **rsLoRA**（Rank-Stabilized LoRA，秩稳定——缩放按 √r 修正）、
    **AdaLoRA**（Adaptive LoRA，秩自适应分配）——知道名字即可；
- **加性前缀类**：**Prefix Tuning**（前缀微调：每层注意力前加可训练前缀 KV）、
  **P-Tuning v2**（Deep Prompt Tuning，深层提示微调——≈ 每层前缀，与 Prefix 基本同义）、
  **Prompt Tuning**（软提示微调：只在输入层加 soft prompt，最省但容量最小）、
  **Adapter**（适配器模块：层间插入小瓶颈模块，**改变推理图有额外延迟**，LoRA 可合并无延迟）；
- **其他**：**IA³**（Infused Adapter by Inhibiting and Amplifying Inner Activations：
  逐通道可训练缩放向量，比 LoRA 更少参数）。

**选型直觉**：改行为（分类/格式/风格/遵循指令）→ LoRA 足够；注入新知识 → CPT 或 FFT
（LoRA 学不进大量新知识，只能引导既有能力的使用方式）。

## 3. 维度③：数值精度 / 量化（怎么省着训）

- **混合精度 bf16/fp16**（BFloat16 / Float16）：默认，权重主副本 fp32 + 计算用 bf16；
- **LLM.int8（8-bit Integer Quantization，8比特整数量化）**：bitsandbytes，主干 8bit，
  早期方案，已被 NF4 取代；
- **NF4（4-bit NormalFloat，4比特正态浮点）**：QLoRA 提出的 4bit 数值格式（信息论最优），
  配双量化与分页优化器；
- **正交性**：量化可与维度①②任意叠加——通常与 PEFT 组合成 QLoRA（训练侧）；
- **区分（易混点）**：训练侧量化（QLoRA/NF4，为了省显存训练）vs **部署侧量化**
  （**GGUF** Q4/Q8、**AWQ**（Activation-aware Weight Quantization，激活感知权重量化）、
  **GPTQ**（GPT Post-Training Quantization，训练后量化），为了省显存推理）
  ——后者与微调方法无关，本项目 ollama 的 Q4 就属于部署侧，别在面试里混为一谈。

## 4. 总表（按维度归位，面试直接用）

| 方法 | 属于哪个维度 | 一句话 | 开销 | 什么时候用 |
|---|---|---|---|---|
| CPT | ①范式 | 领域语料继续"学下一个词" | 大 | 垂直领域基座才用（应用层少做） |
| **SFT** | ①范式 | 指令→标准回答对，学按指令办事 | 中 | 有标准答案的任务对齐（本项目） |
| RLHF | ①范式 | 奖励模型 + PPO 学偏好 | 大 | 无唯一答案的偏好对齐 |
| DPO | ①范式 | 免奖励模型，偏好对直接优化 | 中 | RLHF 的轻量替代 |
| GRPO | ①范式 | 免价值模型的在线 RL，组内相对优势 | 中 | 推理/数学 RL（DeepSeek-R1） |
| FFT | ②范围 | 100% 参数全更新 | 最大 | 数据多、改动力大、资源足 |
| BitFit/部分层 | ②范围 | 只训 bias / 顶层 | 小 | 极端省资源，容量有限 |
| Adapter | ②范围 | 层间插瓶颈模块 | 小 | 早期 PEFT；有推理延迟 |
| Prefix/P-Tuning v2 | ②范围 | 每层可训练前缀 KV | 小 | 与 LoRA 同代竞品 |
| **LoRA** | ②范围 | 低秩旁路 ΔW=BA，可合并 | 小 | **窄任务改行为（本项目）** |
| **QLoRA** | ②×③ | LoRA + 主干 NF4 量化 | 更小 | 12G 小卡训 7B+ |
| DoRA/LoRA+/rsLoRA | ②范围 | LoRA 改进变体 | 小 | 了解即可 |
| 8bit/NF4 | ③精度 | 训练时量化主干省显存 | — | 与②叠加使用 |
| GGUF Q4/AWQ/GPTQ | 部署侧 | 推理量化，与训练无关 | — | 上线部署（ollama 即 GGUF） |

## 5. 面试速答

| 追问 | 一句话回答 |
|---|---|
| SFT 和 LoRA 是一类东西吗？ | 不是：SFT 是训练范式（教什么），LoRA 是参数范围（动多少）；可组合成"LoRA + SFT"（本项目） |
| FFT 和 SFT 的区别？ | 不同维度：FFT/LoRA 说动多少参数，SFT/CPT/RLHF 说用什么数据教什么；原厂 Instruct 版 = FFT + SFT |
| QLoRA 和 LoRA 的区别？ | QLoRA = LoRA + 冻结主干量化 4bit NF4，省的是基座显存；LoRA 旁路本身始终 bf16 训练 |
| RLHF 和 DPO 什么区别？ | 目标同源；RLHF 要训奖励模型再 PPO（重、不稳），DPO 数学变形后免 RM 免 RL，直接偏好对做类分类损失（轻、稳）；都在 SFT 之后 |
| GRPO 和 PPO 什么区别？ | 都是在线 RL；PPO 需额外训价值模型估基线（显存大、不稳），GRPO 同一 prompt 采样一组回答、用组内均值当基线，免价值模型（DeepSeek-R1 采用） |
| 什么时候 RLHF/DPO、什么时候 SFT？ | 有唯一标准答案→SFT；只有相对偏好（语气/安全边界）→DPO/RLHF |
| PEFT 有哪几类？ | 低秩旁路（LoRA 系）、加性前缀（Prefix/P-Tuning v2/Prompt Tuning）、加性模块（Adapter）、缩放（IA³/BitFit） |
| LoRA 能学新知识吗？ | 基本不能——它只引导既有能力的使用方式；注入大量新知识要 CPT/FFT（加分认知） |
| 训练量化 vs 部署量化？ | QLoRA 的 NF4 省训练显存；GGUF Q4/AWQ/GPTQ 省推理显存，两回事 |
