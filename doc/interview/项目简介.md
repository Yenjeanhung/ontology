## 精炼版（口播 30 秒）

该平台为国航运行控制中心建设，服务航班运行监控与特情处置业务，覆盖航班从计划、起飞到落地保障的全生命周期。平台汇聚航路、机场、机组、气象、通告及多业务系统等运行数据，打通「运行监控 → 分析研判 → 特情处置」作业链路，以双引擎驱动智能化：Agentic Workflow 面向告警监控与例行研判，工作流内嵌智能体节点，基于 GraphRAG 图检索自动研判告警处置方案；Multi-Agent 面向复盘、取数、出报告等开放式任务，由任务规划、数据取证、图谱检索、结果合成等分角色智能体组队分工、并行执行——将「多报表人工查数」的传统作业升级为自然语言问答与自动研判，显著缩短信息获取与特情响应时间。

---

## 锚点版（书面 / 追问展开）

**项目背景**：面向国航运行控制中心，围绕航班运行全生命周期的多源数据融合与智能化运营需求，建设一体化运行监控与特情处置支撑平台。

**数据与业务**：整合航路、机场、机组、飞机、气象、机场通告及各业务系统的运行数据，打通「运行监控 → 分析研判 → 特情处置」业务闭环。

**技术亮点**（每条都可展开 3~5 分钟）：

1. **Agentic Workflow 工作流编排（LangGraph 引擎）**：面向告警监控、周期性分析研判等例行场景，以可视化画布编排「取数 → 智能体研判 → 条件分支 → 人工审批 / 结论推送」的 DAG；内嵌智能体节点基于 GraphRAG 图检索增强研判「告警如何处置」——向量 + 关键词 + 知识图谱多路召回、Rerank 精排、图谱多跳扩展，自动关联处置程序、历史案例与影响面，弥补纯文本召回盲区；LangGraph 超步模型自动并行无依赖节点、SSE 流式回传进度，支持定时触发与 human 人工介入节点。

2. **Multi-Agent 分角色智能体团队**：LLM Planner 将复杂问题分解为 2~4 个子任务，按固定角色组队并行执行——Retriever 知识库语义取证、DataAgent 结构化数据查询与统计、GraphAgent 图谱事实抽取、ToolAgent Function Calling / MCP 外部工具调用（如图表生成），Synthesizer 汇总合成结论，可选 Critic 评审质检；面向运行复盘、台账取数、简报撰写等开放式任务，支持任务模板一键组队与自定义智能体（绑定知识库人设）；长短期记忆（会话内滚动摘要 + 用户级长期记忆）保证多轮追问连续性。

3. **业务价值**：从「人工跨系统查数」到「自然语言一问即答」，从「人工盯屏巡检告警」到「工作流定时自动研判推送」——运行监控查询、知识检索、例行研判、复盘报告统一入口，缩短信息获取与决策链路。
