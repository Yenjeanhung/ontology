昆仑智平台                   
项目描述：昆仑智平台是以本体（Ontology）为核心、事件驱动的企业级数据底座：将多个业务系统按系统手动建模为本体——一个系统即一个本体，其下模块对应实体，模块代码封装为实体服务；各系统数据经连接器统一接入，数字线程引擎完成孪生体建模、服务执行与事件发布，经统一网关以 API/SSE 实时推送至知识图谱、组装应用等上层应用。本人负责 kl-dt-engine（数字线程引擎）与 kl-dt-gateway（统一网关）两大核心模块的设计与研发。
平台作为公司的数据底座，已沉淀多领域本体资产供各部门复用：其它系统可直接引用平台中的本体、实体及关系定义快速构建业务应用，避免重复建模与语义不一致，让全公司业务在统一语义标准下协同运转。
技术栈：SpringBoot、Ignite、Kafka、ZooKeeper、Drools、XXL-JOB、FileBeat、Elasticsearch、Redis、OpenTSDB、HBase、NebulaGraph、ManticoreSearch、MySQL/达梦/KingBase、Vue3、Ambari
责任描述：
1）主导平台本体元模型的设计与落地：建立「本体类别 → 本体（类型定义）→ 属性」三级模型与「起点本体 + 关系 + 终点本体」三元组约束体系，把业务知识抽象为可管理、可复用、可校验的语义模型；本体定义与实例数据分层存储，完成 MySQL/达梦/KingBase 信创多数据库适配，支撑平台作为全公司统一数据底座；

2）构建本体语义复用机制：将人员基础信息等共性语义沉淀为全局属性模板，本体按「模板属性 + 自有属性」组合派生，同一语义跨领域只定义一次、口径全局一致，显著降低多领域本体建模成本，避免各系统各自建模造成的语义漂移；

3）负责引擎模块：设计本体服务全生命周期管理（预构建→激活→替换→回滚），本体包含Drools动态规则、Rhino脚本服务执行器，业务逻辑在线定义、即时生效；服务支持编排引用本体函数完成「计算→条件校验→事务写回」，本体函数绑定实体自动派生计算值（派生属性），读时实时计算与定时物化双模式，经 XXL-JOB 调度批量执行；

4）构建平台事件驱动链路：基于 Ignite Messaging 实现事件总线，设计「触发码#事件码」topic 路由规则与订阅匹配树，引擎侧事件毫秒级扇出；网关侧 SSE 长连接实时推送前端，会话多级索引缓存 + 心跳超时巡检，跨网关实例自动定位转发，支撑多客户端产品订阅推送；

5）设计多模存储与双库同步：Ignite 分布式缓存兼内存 SQL 库（ZK 集群发现、WAL FSYNC、双副本分区、ContinuousQuery 缓存变更监听）；实例数据以关系库为权威、知识图谱同步写入 NebulaGraph，分批 UPSERT 幂等导入、会话池过期自愈，图谱查询按度数 TopN 截断防 OOM，保证图谱可视化与业务数据始终一致；

6）独立负责 kl-dt-gateway 统一 API 网关：基于 ZooKeeper 服务发现与引擎集群轮询负载均衡，孪生体服务粘性路由、节点下线自动漂移重建，多实例水平扩展；封装对外 REST 门面与 MCP 协议透传，AOP 状态锁幂等防重（超时自动解锁），traceId 全链路 MDC 追踪，支持云端/边缘双部署形态。
